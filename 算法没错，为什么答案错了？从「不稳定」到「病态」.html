算法没错，为什么答案错了？

————从「不稳定」到「病态」
作者：RainHan | 2026-11-20 | 目标读者：学过线性代数

一个每一步都没算错的算法，为什么会给出看起来离谱的答案？答案是：问题不在算法里。

01评价算法：四个维度，只有稳定独属于算法

衡量一个算法，常用四个词：准确（accuracy）、高效（efficiency）、稳定（stability）、鲁棒（robustness）。混用会导致后面把「算法不稳定」和「问题病态」当成一件事。

准确（accuracy）：答案离真值有多近。度量有两种：绝对误差，取估计值与真值之差；相对误差，取这个差再除以真值的大小[1]。

高效（efficiency）：达到给定精度要花多少资源。通常是时间和空间；中间步骤调用 API（应用程序接口）时，费用也是资源，按次计费，规模一大就是主要成本。资源与精度绑在一起：精度目标提高，资源跟着涨，所以论效率总要带上精度目标[1]。

稳定（stability）：算术只能保留有限位小数，计算限制造成的误差会不会被算法放大？稳定的算法应当限制这种误差的放大

鲁棒（robustness）：换一批数据，结果还靠不靠得住。窄的说法是遇到坏点、离群值（outlier）不崩；宽的说法是算法能在大范围的数据上可靠工作，甚至随机数据上都行[1]。

四个词分属两层：准确、高效、鲁棒评价「问题 + 数据 + 算法」这个整体，稳定只评价算法本身。

准确不达标可能是问题无解，鲁棒不达标可能是数据脏，此时两者与数值误差无关，不能算在算法头上。

结论：稳定性属于算法，良态与病态属于问题，两者必须分开。

02不稳定：算法放大的是舍入误差

实数有无限多位，机器用固定长度的二进制近似，这个近似叫浮点数（floating-point number）。每存一个数，末尾的一截被舍掉。

舍掉的部分叫舍入误差（rounding error）。

另一种误差叫截断误差（truncation error）：用有限步近似无限过程，例如把无穷级数截到前十项、用一千次迭代逼近极限，或把连续问题切成有限网格（离散化，discretization）[1]。截断误差来自近似本身——少算几步，或把连续切成离散——是设计选择；舍入误差来自机器存不下，是硬件限制。前者的修法是加步数、加密网格，后者是换算法或加精度。

不稳定的算法（unstable algorithm）：会把舍入误差越滚越大。

  1. 算式：1016 + 1 − 1016。
  2. 先算 1016 + 1。1016 的二进制是 1 后跟 16 个 0，占 17 位；双精度（double precision）只存约 16 位十进制有效数字，即 53 位二进制。
  3. 那个 1 要占第 17 位，超出范围，被舍掉。1016 + 1 得 1016。
  4. 再算 1016 − 1016，得 0。
  5. 最终发现，算式在数学上等于 1，但浮点计算上等于 0。

常见的说法是「轻微扰动带来巨大变化」。这个说法直观，但为了严谨需要考虑三点:

  1. 相对还是绝对？变化和扰动都要考虑。
  2. 最坏情况（worst case）还是平均情况？或是别的？
  3. 扰动来自哪里？算术误差，还是数据误差？或是别的？
结论：不稳定指算法放大机器误差，这里的扰动指算术误差。

03Wilkinson 1959：系数动一点点，十个整数根变成复数根

取多项式（polynomial）p(x) = (x−1)(x−2)…(x−20)。二十个根（root），全是正整数，相邻间隔 1。

它有两种写法：

  1. 乘积形式，二十个括号相乘。
  2. 展开形式，c20x20 + c19x19 + … + c0。
  3. 两种写法数学上等价，根相同。

展开后，x19 的系数是 −210[2]。Wilkinson 把它改成 −210 − 2−23，重新求根。

改动量：

  1. 绝对量 2−23 ≈ 1.19×10−7。
  2. 相对量 1.19×10−7 / 210 ≈ 5.7×10−10。
  3. 落在第十位有效数字，动了一个单位。

结果分两部分。十个根变成复数（complex number），形成五对共轭（conjugate，实部相同、虚部相反）复根；其余十个仍在实轴，但位置偏移，最远的是 20 → 20.84691[3][4]。

结论：同一个算法，换一份几乎相同的数据，答案从 20 变成 20.8——这不是算法的毛病。

04条件数 κ：把「敏感」变成一个可算的数

同一个问题，输入动一点点，解会被放大多少倍？这个「最坏情况下的相对放大倍数」，就是条件数（condition number），记作 κ。它只由问题本身决定，跟用什么算法无关。

定义分五步：

  1. 取矩阵 A 和右端项 b，解出 x。
  2. 给 b 加一个小扰动 δb，解变成 x + δx，满足 A δx = δb。
  3. 算相对放大比：( ‖δx‖ / ‖x‖ ) ÷ ( ‖δb‖ / ‖b‖ )。
  4. 对所有非零的 b 和 δb 取最大。注意不是固定一个 b、只看扰动方向：固定 b 时这个最大值依赖 b，不是 κ(A)。
  5. 这个最大值就是 κ(A)。
κ(A)  =  maxb, δb [ ( ‖δx‖ / ‖x‖ ) ÷ ( ‖δb‖ / ‖b‖ ) ]对所有非零的 b、δb 取最大；分子分母都是相对量

含义：输入相对误差为 ε 时，输出相对误差最多为 κε。κ 就是这个放大倍数的上界，最坏情况下能取到。它能直接算：κ(A) = ‖A‖ ‖A−1‖（推导与算法见本节选看）。

后果：双精度下可用的十进制有效位数约为 16 − log10κ 位，κ 越大，可信的位越少。推导、换算表和图示见本节选看。

结论：条件数衡量误差的放大倍数，不衡量误差本身的大小。
选看：κ 的推导、范数与计算

为什么最大值等于 ‖A‖‖A−1‖。扰动满足 A δx = δb，所以 δx = A−1δb，‖δx‖ ≤ ‖A−1‖‖δb‖；又 ‖b‖ = ‖Ax‖ ≤ ‖A‖‖x‖，即 1/‖x‖ ≤ ‖A‖/‖b‖。两式相乘，相对放大比 ≤ ‖A‖‖A−1‖。取 b 沿最大的拉伸方向、扰动沿最小的拉伸方向，等号成立，所以这个乘积就是 κ(A)。顺带得到 κ ≥ 1。

范数。两处必须用同一个范数。2-范数下它就是奇异值之比 σmax/σmin（奇异值第 6 节讲）；1-范数是「列和的最大值」，∞-范数是「行和的最大值」，算 κ 时还要乘上 A−1 的同一个范数。三种范数给出的 κ 至多差 n 倍左右，量级一致，但报告时必须注明用的是哪个范数。

计算。2-范数用 SVD，一次 O(n3)，numpy.linalg.cond(A, 2) 一行；矩阵很大时用 1-范数估计器（LAPACK 的 xGECON），只差一个常数倍，比求逆便宜得多。

缩放与相对性。系数组每行乘 2，解不变，但 κ 会变——κ 属于「表示」，不属于矩阵本身。绝对误差没有尺度意义：10−6 的误差在 b ~ 1 和 b ~ 106 下是两回事，所以定义里只用相对量。

分量型条件数（componentwise condition number）按每个元素各自的相对扰动来算。数据只有少数元素不准时，它比范数型更贴切；同一个矩阵按两种口径算，结果能差几个数量级。范数型问「最坏的元素扰动有多大」，分量型问「实际被扰动的那几个元素会放大多少」。

选看：一个 2×2 的算例

A = [[1, 1], [1, 1.0001]]，κ₂(A) ≈ 4.0×104（σmax ≈ 2.0，σmin ≈ 5.0×10−5）。取 b = (2, 2.0001)，解是 x = (1, 1)。

把 b 的第二项从 2.0001 加到 2.0002：数据相对变化 ‖δb‖/‖b‖ ≈ 3.5×10−5，解却变成 (0, 2)——相对变化约 100%。放大倍数约 2.8×104。

这还没到最坏情况：κ₂ ≈ 4.0×104 是上界，取最坏方向时能取到。所以 κ 大不等于每次必错，但它保证放大不会超过这个倍数；κ 小才保证误差不会被放大。

05向后稳定：算法保证了什么，又没保证什么

向后稳定（backward stable）的定义分三步：

  1. 算法输出 x̂。
  2. 判断是否存在小扰动 ΔA、Δb，使 (A + ΔA)x̂ = b + Δb 精确成立。
  3. 若存在，且 ΔA、Δb 与机器精度（machine epsilon，即 1 与比它大的最小浮点数之差）同量级，则算法向后稳定。

误差因此分三段：

  1. 算法把向后误差（backward error）压到机器精度量级。
  2. 问题以 κ 倍把向后误差放大成前向误差（forward error）。
  3. 前向误差 ≲ κ × 向后误差。

稳定算法在病态问题上给出差的答案：自身误差已压到最小，剩余部分来自问题。

结论：稳定保证解的是邻近的问题，不保证原问题可解。
选看：特征值和根各自的条件数

特征值（eigenvalue，满足 Ax = λx 的 λ）的条件数是 1/|yTx|，其中 x、y 是 λ 对应的右、左特征向量，都归一化为单位长度。yTx 量的是两者的「重合度」：对称矩阵左右特征向量相同，yTx = 1，条件数为 1；非对称矩阵两者可以近乎正交，分母接近 0，条件数极大。

所以特征值间距大不等于安全。非正规（non-normal）矩阵即使特征值分得很开，只要左、右特征向量近乎正交，单个特征值仍可能对扰动极敏感。决定敏感度的是这对特征向量的夹角，不是间距。

求根也一样，但公式里不只有导数：系数 ck 扰动 δck 时，根移动约 δck·αk/|p′(α)|。分子随 |α| 变大，分母在整根中间最小——对 ∏(x−k)，|p′(k)| = (k−1)!(20−k)!，前后对称，10、11 附近最小。两头一拉扯，Wilkinson 多项式最敏感的是 14 到 17 一带的根，它们跑得最远、成对进入复平面；20 的分子虽大，分母也大，只挪到 20.85；1 到 5 的分子接近 1，几乎不动——图 1 就是这个形状。

选看：残量不止一种

最常用的是朴素残量 r = b − Ax̂：把算出来的解代回去，看离右端项差多少。它和误差 e = x − x̂ 不是一回事，两者由 Ae = r 联系：A−1 很大时，r 很小 e 仍可以很大（前面那条 前向误差 ≲ κ × 向后误差），但 r 可以直接算，e 通常不知道——所以诊断只能看 r。

相对化与缩放。绝对残量 ‖r‖ 没有可比性，工程上报 ‖r‖/‖b‖（相对残量），或者 ‖r‖/(‖A‖‖x̂‖)（缩放残量）；后者与后向误差只差分母里的 ‖b‖。

后向误差。把残量除以 ‖A‖‖x̂‖ + ‖b‖，得到范数型后向误差 η = ‖r‖ / (‖A‖‖x̂‖ + ‖b‖)[8]。它是最小的 η，使得 (A + ΔA)x̂ = b + Δb，且 ‖ΔA‖ ≤ η‖A‖、‖Δb‖ ≤ η‖b‖——换句话说，x̂ 精确地解了一个被扰动 η 倍的邻近问题。向后稳定算法的 η 就在机器精度量级。

分量型。每个方程单独看：ε = maxi |ri| / ((|A||x̂|)i + |bi|)[9]，量的是每个元素各被扰动多少。数据只有少数元素不准时，它比范数型贴切（与第 4 节选看里的分量型条件数是同一思路）。

最小二乘与迭代法。最小二乘的最优解满足 ATr = 0（残量与 A 的列空间正交），所以实践中常检查 ATr 而不是 r；A 病态或秩亏时，两种残量的量级可以差很多——前者问「方程差多少」，后者问「梯度是否为零」。迭代法（CG、GMRES）里还分「算法递推的残量」和「重新算的真实残量」，长迭代会漂移，所以要定期重算。

06病态的实质：约束不独立，不是数太大

良态（well-conditioned）与病态（ill-conditioned）：

  1. 良态：约束互相独立，每条新约束提供一个新方向的信息。
  2. 病态：约束近似重复，名义上多条，独立方向不足。

几何上对应两条近似平行的直线：

  1. 第一条线给出一个约束。
  2. 第二条线本应给出另一个方向。
  3. 它与第一条近似平行，给出的仍是同一方向。
  4. 两个方向退化为一个，剩余方向数据看不见，交点位置不稳定。

矩阵语言：近秩亏（near rank deficiency）。最小奇异值（singular value，矩阵在各方向上的拉伸倍数）σmin 很小，存在一个方向矩阵几乎不作用，该方向的分量无法准确测出。

奇异（singular）是它的极端。对方阵，det A = 0，等价于存在非零向量 x 使 Ax = 0：某个方向被完全压成零，A 不可逆，Ax = b 要么无解、要么有无穷多解——不是「不好解」，是没有唯一解。近秩亏则是「差不多奇异」：σmin 很小但没到零，解存在，只是对数据极敏感。第 8 节第 4 步说「事实上奇异」，指的就是 σmin 小到在当前精度下与零无法区分。

病态与元素大小无关：108I 的 κ = 1；Hilbert 矩阵（Hilbert matrix）元素为 1/2、1/3，n = 12 时 κ 达 1016 量级[6]，双精度下不可解。

结论：病态是约束不独立，不是数值太大。
选看：SVD 与病态

任何矩阵都能分解成「旋转 → 沿坐标轴拉伸 → 再旋转」：A = UΣVT。奇异值 σ 就是各方向的拉伸倍数，最大 σmax、最小 σmin。

求逆是同一件事倒过来：A−1 = VΣ−1UT，原来被拉长 σ 倍的方向，现在要除以 σ。误差在 A 和 A−1 之间来回一趟，最坏放大 σmax/σmin 倍——这就是 κ。

例子：A = diag(103, 1)，b = (103, 0) 时解是 (1, 0)。把 b 的第二个分量从 0 改成 1，相对变化只有千分之一，解却变成 (1, 1)——第二个分量从 0 跳到 1。短轴方向几乎量不出来的那点信息，到解里被放大了三个数量级。

几何上，κ 就是单位球被 A 拉成的椭球的扁度：越扁，求逆时误差放大越多。一条轴被压到近零，等于少了一个独立方向，与第 6 节说的「约束近似重复」是同一件事。

选看：正则化用一点偏差换稳定

病态问题既换不了数据、也换不了表述时，通常加一个惩罚项：minx ‖Ax − b‖² + λ‖x‖²，解为 xλ = (ATA + λI)−1ATb。

λ > 0 把 ATA 的最小特征值从 σmin² 抬到 σmin² + λ，有效条件数从 σmax²/σmin² 降到 (σmax² + λ)/(σmin² + λ)。λ 越大，噪声被压得越狠。

代价是偏差：λ 越大，解越被拉向「短」的方向，离开真解越远。选 λ 就是在噪声放大与偏差之间做交换。第 8 节检修表里「正则化」那一条，说的正是这件事；矩阵补全里的低秩近似，也是把精确约束换成了带惩罚的近似。

07矩阵补全：换观测模式，就是换问题

矩阵补全（matrix completion）说的是：一张表里大部分格子是空的，按「表是低秩的」把空格填出来。Netflix 的用户×电影评分表就是典型——每人只看过几十部片子，其余全是空缺；低秩的意思是口味相近的人打分也相近，于是行与行高度相关。哪些格子被观测，称为观测模式（observation pattern）；这里只讨论确定模式，不是随机抽样。

核心只有一句：低秩 = 行与行有强关系 = 信息冗余。一行如果能由别的行组合出来，它缺的格子就能推；秩越低，冗余越大，能推出来的越多。这是「补全」能成立的全部理由。

但能推出来，不等于推得唯一。看下面这张 6×6 乘法表：第 i 行第 j 列是 i×j，秩为 1；第 5 行整行没被观测。

秩为 1，说明第 5 行必须是 (1,2,3,4,5,6) 的某个倍数。观测只能给倍数加上限制，却定不下它是几。填 5 倍、填 10 倍，都与已知格子一致，秩都是 1。所以这一节真正的问题不是「怎么补」，而是给定观测模式，解是否唯一。

唯一的条件，粗略地说：观测要能把行与行之间的比例钉死。每一行都被看到过一点，而且这些观察不总落在同样的几列上，比例就能定；只要有一整行（或一整列）完全没被看到，它就可以随意伸缩，解必然不唯一。观测的位置和数量，本身就在决定问题能不能解。

换个说法。把所有低秩矩阵看成一个曲面（流形），把「符合观测」看成约束，解就是两者的交点。横截地相交，交点孤立，问题良态；近乎相切，交集成一整段，解不唯一，数据一动解就滑走。

同一个矩阵、同一套算法，观测的格子换一换，问题可以从良态变病态——这就是标题的意思。

结论：换观测模式就是换问题；算法不变，良态与病态可以互换。
选看：要看多少个格子才够

数一下自由度就明白了。n×n 的秩 r 矩阵能写成 M = UVT，U、V 各 n×r，一共 2nr 个参数；但 U → UQ、V → VQ−T 得到同一个 M，重复数了 r2 次。自由度是 r(2n − r)。

观测数少于这个数，一般不可能唯一确定矩阵；多于它，也不保证——位置同样重要，这正是「观测模式」的意思。

量级感受一下：n = 1000、r = 10 时自由度约 2×104，而格子总数是 106。看到约 2% 的格子，信息量就够补全——前提是这些格子别都挤在几行里。

选看：最小秩与低秩近似，两种写法

同一个问题，可以写成两种优化。记观测到的元素为 X、待补的矩阵为 M、观测位置集合为 Ω[1]：

写法优化问题
最小秩minM rank(M)，约束 Mij = Xij，其中 (i,j) ∈ Ω
低秩近似minU,V Σ(i,j)∈Ω (Xij − [UV]ij)2

两种写法面对的是同一组观测。上面是等式约束，秩只能取整数，数据一动，解可能落到另一个秩上，答案跳变；下面把秩固定成 U 的列数，把等式放松成最小二乘，解连续地依赖数据。秩跳变带来的不稳定就此消失，这就是第 4 条结论的机制。

选看：Shapiro–Xie–Zhang 的四条结论

Shapiro、Xie、Zhang 2018 从几何角度处理最小秩矩阵补全（minimum rank matrix completion，MRMC），把「解是否唯一」写成可代数验证的条件[5]：

  1. 给出可代数验证的充分条件，称良态条件（well-posedness condition），保证局部唯一（local uniqueness）。
  2. 该条件近乎必要：例外情形极少；同时是局部稳定性的必要条件。
  3. 用 characteristic rank（矩阵在一般位置上能达到的秩）证明它一般成立：多数观测模式良态，病态是特例。
  4. 低秩近似（low-rank approximation）比直接求最小秩更稳定。

这四条不必记住。主文用到的只有一句：良态与否由观测模式决定，而低秩近似比直接求最小秩更稳。

选看：横截性（transversality）

两个子流形 M、N 在交点 p 处横截，指它们的切空间加起来张满整个空间：TpM + TpN = 全空间。这时交集「不多不少」，维数正好是 dim M + dim N − dim(全空间)。

不横截时，两个切空间合起来还差一截，交集就会比预期多出至少一维：本应是孤立点，结果成了一条曲线或一个曲面。矩阵补全里，低秩流形与观测约束的切空间不横截，解就从孤立点变成一族。

良态条件本质上就是这个横截条件的一个可代数验证的版本：把「两个切空间张满」写成矩阵的秩条件，就能对方程组做计算验证。

08启发：结果和预期不符，究竟是算法还是别的原因

结果和预期不符时，不一定是算法的责任。先定责，再动手。下面五步，每一步排除一种责任：

  1. 换等价算法（第 1、2 节）。两种实现各算一遍：结果明显改善，责任在算法；几乎不变，继续下一步。
  2. 算相对残量：‖r‖/‖b‖，其中 r = b − Ax̂，最好用更高精度重算（第 5 节）。残量小、答案错，说明问题病态；残量大，说明算法没收敛或算错。
  3. 轻微加噪：给数据加很小的噪声，重算十次左右（第 3、4 节）。解大幅变化，说明问题病态；几乎不动，说明问题不敏感，回去查算法。
  4. 算敏感度：κ 衡量问题有多敏感（第 4 节），再乘机器精度 ε。乘积接近 1 时，矩阵在该精度下已事实上奇异（numerically singular），只能提精度或换问题。
  5. 换等价表述：中心化、换基、重新缩放（第 6、7 节）。换完明显变好，说明病态来自表述，可以避开；不变，说明问题本身病态。

按上面的顺序读这张表（「步」一列就是五步的编号）：先确认自己在第几步，再看遇到的是哪种情景，最后看下一步。

步情景该怀疑谁下一步
1换算法换了等价算法，结果明显变好算法用新算法，收工
1换算法不知道该换什么算法，或者换了没变化先不下结论别停在这里，做第 2 步（算相对残量）
2算残量相对残量已到 10−16，答案却错问题（病态）做第 4 步（算敏感度），再做第 5 步（换等价表述）
2算残量相对残量停在 10−3 量级，换算法也不降算法没收敛，或数据、模型有错查收敛；核对数据与模型
3加噪加 10−8 噪声，解放大 103 倍以上问题（病态）换表述；不行就正则化
4算敏感κ·ε 接近 1（10−1 以上）精度不够提精度、降规模或换问题
4算敏感残量小、κ·ε 也小，答案仍不对问题定义或模型，不是数值误差回第 1 节：换问法或换模型
5换表述换了表述，解明显变好病态来自表述采用新表述，别再加精度
5换表述换了表述也没变化问题本身病态正则化，或换问题

表里的 10−16 是按双精度写的，单精度下换成 10−7；κ·ε 的 10−1 在两种精度下通用。

在后面的选看里，这五步怎么查、看什么、怎么判会逐条展开。另附我觉得非常有趣的，与每条都有关的 Runge 现象。

本篇文章按一条误差链展开：算法把误差压到机器精度量级，问题把它放大 κ 倍。第 1、2 节界定「稳定」「不稳定」到底指什么，第 3 节演示责任怎么从算法滑到数据，第 4 节给出放大的倍数，第 5 节把这条链写成不等式，第 6 节给出病态的几何实质，第 7 节说明换问题才是最彻底的解法，本节把整条链折成一张排查表。

排查顺序不能调换：先有责任的分层，才有排查的先后。省掉这个结构的代价很具体：把病态当成不稳定，会把所有算法试一遍；把不稳定当成病态，会一直加精度。开刀的位置和病因当然要在同一侧。

结论：先定责，再动手。病因搞错了，换算法和加精度都白费。
选看：五种责任，怎么查、看什么、怎么判

第 1 步 · 换等价算法

做什么：数学问题不变，换一个数值更稳的实现。常见三处：正规方程 ATAx = ATb 换成 QR 或 SVD；方差用 E[x2] − E[x]2 换成先减均值（或 Welford 单遍）；大量数求和换成 Kahan 补偿或两两相加。矩阵分解里把 Gram–Schmidt 换成 Householder、迭代法加预条件，也算这一步。

看什么：同一份数据、两种实现，解相差多少，量级是否超出 κ·ε 该有的范围。

怎么判：换完差几个数量级，责任在算法；几乎不变，继续第 2 步。前提是两种算法都向后稳定——拿不稳定的实现当基准会误判。

第 2 步 · 算相对残量

做什么：算 r = b − Ax̂，用更高精度重算一遍（否则 r 本身就带舍入误差），报相对值 ‖r‖/‖b‖；有条件再算后向误差 η = ‖r‖ / (‖A‖‖x̂‖ + ‖b‖)（见第 5 节选看）。

看什么：残量小到什么程度，和解的可信度是否匹配。相对残量 10−16、解却差 10−2，就是病态；η 在机器精度量级，说明算法没问题。

怎么判：残量小、解错 → 问题侧（第 4、5 步）；残量大 → 算法没收敛或算错（回第 1 步）。插值的残量恒为 0，这一步对插值无效。

第 3 步 · 轻微加噪

做什么：给数据加相对 10−8～10−6 的随机扰动，重算十次左右；也可以逐列、逐行扰动，看哪个方向最敏感。

看什么：解的变化幅度除以数据的变化幅度。接近 1 是良态，到 103 以上是病态。

怎么判：解大幅跳 → 病态；几乎不动 → 问题不敏感，回去查算法。这一步不用算 κ、不用换算法，先做。

第 4 步 · 算敏感度

做什么：敏感度用 κ 量：κ₂(A) = σmax/σmin，numpy.linalg.cond 一行就能算；再乘机器精度 ε（双精度约 2.2×10−16，单精度约 1.2×10−7）。

看什么：κ·ε。0.5 以上基本没有有效数字；10−4 只剩四位，10−8 剩八位。

怎么判：κ·ε 接近 1 → 提精度或换问题；远小于 1 却仍出错，说明错误不来自舍入，回去查模型和数据。κ 只对连续扰动有效，矩阵补全那种离散的秩跳变不适用。

第 5 步 · 换等价表述

做什么：不改数据、不改算法，只换写法。常用四类：中心化/标准化（每列减均值、除标准差）；换基（近共线的基换正交基）；缩放（每行乘常数、变量重新标度）；参数化（局部坐标 x = x0 + δ）。拟合问题还可以换节点，Runge 现象换 Chebyshev 节点就是一例。

看什么：换表述后 κ 和残量怎么变，解怎么变。

怎么判：答案明显变化 → 病态来自表述，可以避开；几乎不变 → 问题本身病态，只剩正则化或换问题（第 6 节选看）。

选看：正规方程为什么要先换掉

第 1 步最典型的例子是正规方程（normal equation）：把 ATAx = ATb 当普通方程来解。写法简单，代价是条件数被平方：κ₂(ATA) = κ₂(A)²。

A 的 κ 是 108 时，ATA 的 κ 就是 1016——双精度下一位有效数字都不剩。这时换多好的求解器都没用，因为病态度在第一步就被放大了两次。

QR 分解不做这一步：A = QR，解 Rx = QTb 只需回代，条件数维持在 κ(A)。所以第 1 步换算法，换掉的是那个会把 κ 平方的中间步骤，不是换一个更快的求解器。

选看：Runge 现象——高次插值为什么会崩

在 [−1,1] 上取等距节点，用高次多项式插值 f(x) = 1/(1+25x2)：次数越高，两端振荡越凶，误差不降反升。每一步计算都没错，坏在「等距节点 + 高次多项式」这个表述上。

数字（Runge 1901 的例子，本机计算[7]）：n = 10 时最大误差约 1.9，n = 20 时约 60；中间部分其实很好，误差全堆在两端。同一批 21 个点上改用 5 次最小二乘，最大误差 0.34。

为什么次数越高越糟：插值误差满足 ‖f − pn‖ ≤ (1 + Λn)·En(f)，Λn 是 Lebesgue 常数，En 是最佳逼近误差。f 是解析函数，En 下降很快；但等距节点的 Λn 随 n 指数增长，最后这一项说了算。直觉上，插值必须穿过每个观测，等于把每个点都当成精确，等距节点又让它对微小的数据扰动越来越敏感。

换个角度，插值就是在解 Vandermonde 方程组 Vc = y。节点等距时 V 的条件数同样随 n 快速增长（n = 10 时 1.4×104，n = 20 时 8.3×108）——又回到第 4 节的 κ：不是算法不会解，是这组方程本来就病态。

两个修法对应两种「换表述」：Chebyshev 节点把 Λn 压到只按 log n 增长，次数可以放心加；回归干脆放弃「穿过每点」，用远少于数据点的参数，把噪声留在残差里。这和第 5 步是同一个动作：先换表述，再谈精度。

按第 8 节的分责：这属于第 5 步（换表述），节点分布本身就是表述的一部分；诊断可以用第 3 步——给节点值加一点噪声，高次插值立刻剧烈变化；第 2 步对它失灵（插值残量恒为 0）。严格说它不落在第 1 步：插值与回归不是等价算法，换回归属于换问题，比换算法更彻底。
